# 동일고무벨트 피드백 요청: 질문과 한국어 시연 영상 구성

## 피드백 질문 4개

각 항목에 **1–5점**, **평가 이유 한 문장**, **우선 보완할 점 한 가지**를 부탁드립니다. `1점=목적에 맞지 않음`, `3점=보완 후 검토 가능`, `5점=다음 단계에 활용 가능`을 기준으로 합니다. 판단하기 어려우면 `판단 보류`로 남겨주셔도 됩니다.

| 항목 | 질문 | 영상에서 함께 보여줄 근거 |
| --- | --- | --- |
| ① 구현·시연 수준 | **사진 검사부터 변화 경보, 구간 요약, 검수 요청, 기준 갱신 판단까지 현재 시연이 다음 개발 단계를 논의하기에 충분합니까?** | 실제 화면에서 입력·결과·검수 응답·갱신 보류까지 이어지는 흐름 |
| ② 사용 데이터의 적절성 | **고무벨트 사진을 확보하기 전, 시간순 생산 사진인 TSFabrics로 변화와 검수 흐름을 시험한 선택이 적절합니까?** | 초기 KolektorSDD 사진과 TSFabrics 연속 사진의 차이, 22개 시나리오·93,196장 구성. 보완 의견에는 고무벨트 적용 전에 필요한 촬영 조건이나 검증 자료를 요청 |
| ③ 방법론의 타당성 | **이상 위치와 전체 외관 변화를 분리하고, 시간상 떨어진 소수의 사진을 검수하며, 후속 평가로 기준 갱신 여부를 정하는 절차가 타당합니까?** | DINOv2 히트맵·변화 신호, 간격을 둔 상위 검수 후보, 우선 2건 후 필요 시 6건 추가, 후속 평가에서 갱신 보류 |
| ④ 실무 활용 가능성 | **구간 요약과 검수 후보 화면이 AI 솔루션팀의 현장 확인 요청과 결과 공유에 도움이 되겠습니까?** | 처리 장수·점수 추이·변화 경보·확인 후보를 한 화면에 표시. 보완 의견에는 필요한 보고 항목·전달 형식·담당 흐름 중 우선순위를 요청 |

응답란은 네 행에 `점수(1–5) / 이유 / 우선 보완점` 세 칸만 둔다. 담당자가 특정 항목을 판단하기 어렵다면 점수 대신 `판단 보류`를 적을 수 있게 한다.

## 시연 영상: 약 4분 30초

**형식:** 1920×1080 화면 녹화와 한국어 내레이션. 사이트 화면은 영어 그대로 사용하고, 중요한 용어만 짧은 한국어 자막으로 덧붙인다. 시연은 저장된 TSFabrics 사진과 모델 결과를 재생하며, 검수 응답은 요청된 사진의 공개 데이터 정답을 사용한다. 검수 전 화면에 정답을 먼저 보여주지 않는다.

## 촬영·편집 원칙

- **한 구간 시연과 별도 평가를 구분한다.** 히트맵 예시는 여러 구간에서 골랐고, 변화·검수 화면은 한 녹화 구간을 따른다. 마지막 기준 갱신 판단은 별도의 15개 구간 평가 결과다. 장면이 바뀔 때 화면 상단의 범위 표기를 유지한다.
- **검증 수치의 의미를 표시한다.** AP는 결함 사진의 순위 지표, `15/16`은 서로 다른 녹화 구간을 알려진 경계에서 연결한 변화 시험, `15→26/90`은 같은 8건 검수 예산에서의 사건 발견 건수다. 2×2 표의 두 개선 경로는 같은 최종 조합으로 끝나므로 합산하지 않는다. 기준 사진 선별의 경보 건수는 같은 크기의 기준 뱅크에 각각 원본 구간에서 보정한 경보선을 적용한 결과다. 서로 다른 데이터셋인 초기 MVP와 개선 버전의 수치를 직접 대결시키지 않는다.
- **독립 검증처럼 말하지 않는다.** 2×2 검수 비교에는 이전 실험에서 살펴본 공개 구간이 포함되므로 기술 검증으로 소개한다. 새 생산 구간과 실제 고무벨트에서의 재현성은 별도 후속 평가로 남긴다.
- **화면 기록은 실제 사이트에서 한다.** 기존 [29초 1080p GIF](https://gohyunsu.github.io/surface-trace/media/recorded-run-1080p.gif)는 무음 삽입 장면으로 사용할 수 있다. 한국어 설명이 필요한 본 영상은 음성과 자막을 넣은 MP4로 편집한다. 구간 요약은 GIF에 없으므로 사이트의 `interval.html`을 별도로 녹화한다.
- **검수 결과에 따른 자동 갱신은 시연하지 않는다.** 기준 뱅크 갱신뿐 아니라, 검수된 정상 사진으로 경보선만 올리는 대안도 후속 평가에서 정상 경보와 함께 결함 탐지가 줄었다. 두 대안 모두 보류하고, 검수 결과는 후보를 평가하는 근거로 보여준다.
