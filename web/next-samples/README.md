# Recorded production-frame examples

These 24 TSFabrics test frames were selected to show correct detections, missed
defects, false alarms, and normal cases. Selection used the public labels for
illustration only. The operational reference, thresholds, change detector, and
candidate reference were built without defect labels. The page replays saved
DINOv2 model outputs; it does not run that model in the browser.

The page groups examples by production run and orders frames within each run.
“Handcrafted” is the eight-feature baseline. “Frozen DINOv2” uses the
selected source-run reference and source threshold. “Run-local trial” uses a
new reference and threshold from earlier unlabeled frames of the selected test
run. It is separate from the reviewed-normal candidate shown on the Review &
update page, and neither trial is adopted automatically. The first 12 sample IDs
retain their original frame identities; the additional examples have IDs 13–24.
The catalog stores zero-based frame indices; visible frame numbers add one.

`intervals.json` is generated by `scripts/export_interval_summary.py` from the
recorded experiment results. It contains only the number of eligible frames,
model-flagged frames, and visual-change alerts for the source holdout and each
complete target evaluation interval. No ground-truth labels or confusion counts
or saved shadow-candidate results enter the operational summary. Its flagged-photo previews are a subset of the
curated 24-photo catalog, not the full review queue. The four startup review
photos for the all-normal
changed run come from `web/scenario/manifest.json` and precede its calibration
and evaluation frames. Human choices stay in the current browser session until an
interval report is exported; they do not change the saved model or scores.

Source: Ni et al., *TSFabrics*, Scientific Data (2026),
https://doi.org/10.1038/s41597-026-06748-9; dataset
https://doi.org/10.6084/m9.figshare.29573381 (CC BY 4.0). The photos were
resized/compressed, and the transparent red overlays were generated from model
patch scores. See `experiments/unsupervised/export_site_samples.py` for the
selection and export procedure.
