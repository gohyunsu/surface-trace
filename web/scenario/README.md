# Scenario illustration

`reference-run.jpg` is a real TSFabrics frame (`T1_S174_I111_1`, frame 30)
exported by `experiments/unsupervised/export_animation_data.py` as
`reference_00.jpg`. The adjacent changed-run image on the landing page is
`web/next-samples/sample-06.jpg` (`T1_S164_I36_1`, frame 1263), an annotated
normal frame from a separate production scenario. The pair illustrates the
fixed-reference, changed-appearance test; it is not a before/after view of one
physical process event.
